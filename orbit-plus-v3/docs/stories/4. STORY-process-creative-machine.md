# PROCESS_SECTION_SPEC.md

## Concept: The Machine Room

The Process section reveals glimpses of an ever-running machine through scrolling panel cutouts. The gears exist whether you see them or not—you're catching fragments through rectangular windows as panels scroll past.

**Core metaphor:** Peering into machinery, not showcasing components.
```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   You never see the whole machine.                          │
│   You catch glimpses.                                       │
│   The work happens regardless.                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Depth-Based Rendering

| Depth | Opacity | Scale | Blur | Rotation Speed |
|-------|---------|-------|------|----------------|
| 1.0 | 100% | 1.0x | 0px | 100% |
| 0.9 | 85% | 0.97x | 0px | 95% |
| 0.8 | 70% | 0.94x | 0px | 90% |
| 0.7 | 55% | 0.91x | 1px | 85% |
| 0.6 | 40% | 0.88x | 1px | 80% |
| 0.5 | 30% | 0.85x | 2px | 75% |
```typescript
const getGearStyles = (depth: number) => ({
  opacity: 0.3 + depth * 0.7,
  scale: 0.85 + depth * 0.15,
  filter: depth < 0.8 ? `blur(${(1 - depth) * 5}px)` : 'none',
});

const getRotationSpeed = (depth: number, baseSpeed: number) => {
  return baseSpeed * (0.75 + depth * 0.25);
};
```

### Gear Rotation

Gears rotate continuously based on scroll velocity. Direction alternates for visual realism.
```typescript
// Base rotation: degrees per scroll percentage point
const BASE_ROTATION_RATE = 720; // Full section scroll = 2 full rotations

// In animation loop:
const rotation = scrollProgress * BASE_ROTATION_RATE * gear.dir * getRotationSpeed(gear.depth, 1);
```

## Panel Mask Implementation

The panel layer is a single element with multiple rectangular cutouts. Implemented via SVG mask or CSS clip-path.

### SVG Mask Approach (Recommended)
```tsx
function PanelMask({ scrollProgress }: { scrollProgress: MotionValue<number> }) {
  // Panel Y position (scrolls naturally with content)
  // The mask moves with scroll, revealing different parts of fixed gears
  
  return (
    <svg 
      className="absolute inset-0 w-full h-[400vh] pointer-events-none"
      preserveAspectRatio="none"
    >
      <defs>
        <mask id="panel-mask">
          {/* White = panel visible (blocks gears) */}
          <rect width="100%" height="100%" fill="white" />
          
          {/* Black = cutout (reveals gears) */}
          {CUTOUTS.map(cutout => (
            <rect
              key={cutout.id}
              x={`${cutout.x}%`}
              y={cutout.y} // Positioned in scrollable space
              width={cutout.w}
              height={cutout.h}
              fill="black"
              rx="4" // Slight rounding
            />
          ))}
        </mask>
      </defs>
      
      {/* Panel surface with mask applied */}
      <rect
        width="100%"
        height="100%"
        fill="var(--color-bg)"
        mask="url(#panel-mask)"
      />
    </svg>
  );
}
```

### Cutout Position Calculation

Cutouts need to be positioned in the scrollable panel space (400vh tall) such that they align with gears at the right scroll moment.
```typescript
// Convert scroll-relative timing to panel-space Y position
const getCutoutPanelY = (cutout: Cutout, viewportHeight: number) => {
  // scrollIn 0.16 means "visible when scroll is at 16%"
  // In a 400vh panel, that's position = scrollIn * 400vh - viewportHeight
  const panelHeight = viewportHeight * 4; // 400vh
  return cutout.scrollIn * panelHeight;
};
```

### Parallax + Fade Implementation
```tsx
function ParallaxLabels({ scrollProgress }: { scrollProgress: MotionValue<number> }) {
  // Labels move at 0.6x scroll speed
  const labelY = useTransform(scrollProgress, [0, 1], ['0%', '-60%']);
  
  return (
    <motion.div 
      className="sticky top-0 h-screen pointer-events-none z-30"
      style={{ y: labelY }}
    >
      {LABELS.map(label => {
        const cutout = CUTOUTS.find(c => c.id === label.cutoutId)!;
        
        // Fade in/out based on cutout visibility
        const opacity = useTransform(
          scrollProgress,
          [
            cutout.scrollIn - 0.02,  // Start fade in
            cutout.scrollIn + 0.04,  // Fully visible
            cutout.scrollOut - 0.04, // Start fade out
            cutout.scrollOut,        // Fully hidden
          ],
          [0, 1, 1, 0]
        );
        
        return (
          <motion.div
            key={label.id}
            className="absolute"
            style={{
              left: `${cutout.x + label.offsetX}%`,
              top: `${cutout.y + label.offsetY}%`,
              opacity,
            }}
          >
            <h3 className="font-display text-3xl md:text-5xl text-fg">
              {label.text}
            </h3>
            <p className="text-fg/60 text-sm md:text-base mt-2">
              {label.subline}
            </p>
          </motion.div>
        );
      })}
    </motion.div>
  );
}
```

### Process.tsx (Shell)
```tsx
import { useRef } from 'react';
import { useScroll, useTransform, useSpring } from 'framer-motion';
import { GearField } from './GearField';
import { PanelMask } from './PanelMask';
import { ParallaxLabels } from './ParallaxLabels';

export function Process() {
  const containerRef = useRef<HTMLDivElement>(null);
  
  // Section scroll progress (0-1)
  const { scrollYProgress } = useScroll({
    target: containerRef,
    offset: ['start start', 'end end'],
  });
  
  // Smoothed for gear rotation
  const smoothProgress = useSpring(scrollYProgress, {
    stiffness: 100,
    damping: 30,
    mass: 0.5,
  });
  
  // Scroll velocity for rotation speed
  const velocity = useVelocity(scrollYProgress);
  const smoothVelocity = useSpring(velocity, {
    stiffness: 200,
    damping: 50,
  });

  return (
    <section 
      ref={containerRef}
      id="process" 
      className="relative h-[400vh]"
    >
      {/* Layer 1: Gears (pinned) */}
      <GearField 
        scrollProgress={smoothProgress} 
        scrollVelocity={smoothVelocity}
      />
      
      {/* Layer 2: Panel mask (scrolls normally) */}
      <PanelMask />
      
      {/* Layer 3: Labels (parallax) */}
      <ParallaxLabels scrollProgress={scrollYProgress} />
    </section>
  );
}
```

### Gear.tsx
```tsx
import { motion, MotionValue, useTransform } from 'framer-motion';
import { useMemo } from 'react';
import { gearPath } from './gearPath';

type Props = {
  gear: GearData;
  scrollProgress: MotionValue<number>;
  scrollVelocity: MotionValue<number>;
};

const BASE_ROTATION = 720; // Degrees per full section scroll

export function Gear({ gear, scrollProgress, scrollVelocity }: Props) {
  const { id, cx, cy, r, teeth, dir, depth } = gear;
  
  // Generate gear teeth path
  const path = useMemo(() => gearPath(r, teeth), [r, teeth]);
  
  // Rotation based on scroll progress
  const speedMultiplier = 0.75 + depth * 0.25;
  const rotation = useTransform(
    scrollProgress,
    [0, 1],
    [0, BASE_ROTATION * dir * speedMultiplier]
  );
  
  // Depth-based styling
  const opacity = 0.3 + depth * 0.7;
  const scale = 0.85 + depth * 0.15;
  const blur = depth < 0.8 ? `blur(${(1 - depth) * 5}px)` : 'none';
  
  return (
    <motion.g
      style={{ 
        rotate: rotation,
        originX: `${cx}%`,
        originY: `${cy}%`,
      }}
    >
      <g 
        transform={`translate(${cx}, ${cy}) scale(${scale})`}
        opacity={opacity}
        filter={blur}
      >
        {/* Gear teeth */}
        <path 
          d={path} 
          fill="none" 
          stroke="currentColor" 
          strokeWidth={0.3}
          className="text-fg/40"
        />
        
        {/* Hub */}
        <circle 
          cx={0} 
          cy={0} 
          r={r * 0.15} 
          fill="currentColor"
          className="text-fg/20"
        />
        
        {/* Center dot */}
        <circle 
          cx={0} 
          cy={0} 
          r={r * 0.05} 
          fill="currentColor"
          className="text-fg/60"
        />
      </g>
    </motion.g>
  );
}
```

### gearPath.ts
```typescript
/**
 * Generate SVG path for gear outline with teeth
 * Uses polygonal teeth (not involute) for visual clarity
 */
export function gearPath(radius: number, teeth: number): string {
  const innerR = radius * 0.82;  // Root circle (valley between teeth)
  const outerR = radius * 0.98;  // Tip circle (tooth peaks)
  
  const points: string[] = [];
  
  for (let i = 0; i < teeth; i++) {
    const angle1 = (i / teeth) * Math.PI * 2;
    const angle2 = ((i + 0.5) / teeth) * Math.PI * 2;
    
    // Tooth tip
    const x1 = Math.cos(angle1) * outerR;
    const y1 = Math.sin(angle1) * outerR;
    
    // Valley
    const x2 = Math.cos(angle2) * innerR;
    const y2 = Math.sin(angle2) * innerR;
    
    points.push(
      `${i === 0 ? 'M' : 'L'} ${x1.toFixed(2)} ${y1.toFixed(2)}`,
      `L ${x2.toFixed(2)} ${y2.toFixed(2)}`
    );
  }
  
  return `${points.join(' ')} Z`;
}
```

## Performance Requirements

### GPU-Only Transforms
- Gear rotation: `transform: rotate()`
- Parallax movement: `transform: translateY()`
- Fade transitions: `opacity`
- No `width`, `height`, `top`, `left` animations

### Memory Management
- Gear SVG paths computed once via `useMemo`
- Single SVG element for all gears (batched rendering)
- No DOM nodes created/destroyed during scroll

### Target Metrics
- 60 FPS during scroll
- < 16ms frame budget
- No layout thrashing (no `getBoundingClientRect` in scroll handlers)

## Acceptance Criteria

1. **Peephole Effect:** Gears visible only through rectangular cutouts; never see full machine
2. **Continuous Motion:** Gears always spinning (scroll-velocity driven), regardless of cutout visibility
3. **Sequential Reveals:** Strategy → Design → Build labels appear in order with parallax
4. **Depth Perception:** Gear field has visual depth (opacity/blur/speed variation)
5. **Smooth Parallax:** Labels move slower than panels, creating depth
6. **Performance:** 60 FPS on modern hardware; no jank during fast scroll
7. **Reduced Motion:** Static gears, instant transitions; full content accessible
8. **Theme Aware:** Colors adapt to light/dark theme
9. **Emblem Integration:** Main emblem fades out during Process (gears replace it)

## What Success Looks Like

> You scroll into Process. A tiny rectangle reveals... something moving? Teeth. Gears. You keep scrolling. A larger window opens—two gears meshing, "Strategy" floating nearby. The window passes. Another glimpse, far right. Then the biggest window yet: "Design" as gears interlock. Brief textures. "Build" through another window. A final tiny peek. The machine continues, whether you watch or not.

## What Failure Looks Like

- Seeing the entire gear field at any point
- Gears stopping when no cutout is visible
- Labels appearing without associated gear glimpse
- Cutouts feeling random rather than choreographed
- Parallax causing labels to misalign with cutouts
- Jank during scroll
