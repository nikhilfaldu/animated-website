## Title

The “Proof Bloom” — The One Perfect Surprise Moment

## Goal

Deliver a singular, emotionally resonant “aha” moment that fuses motion, meaning, and user agency.
When the user **clicks and holds** on the constellation during the **Proof (Data) phase**, the frozen network **blooms**—nodes brighten, lines refract, and a luminous flower-like formation unfolds from the emblem’s center.
It lasts only a few seconds, but feels like discovering the hidden soul of the system.

This event embodies the principle of *70% clarity, 30% magic*: it’s clear enough to feel deliberate and meaningful, yet unexpected enough to leave an imprint.

---

## Narrative Link

**Act 4 → Act 5 Transition.**
In the Proof act, the user sees structure emerging from chaos. The Bloom represents the moment of revelation—where all the gathered insights align, and creativity becomes enlightenment.
The constellation’s geometry momentarily synchronizes around the emblem’s origin before dissolving into the vortex of the final act.

> Symbolically: *Order achieves self-awareness, then lets go.*

## State Model

```
bloom: {
  idle       // default constellation
  triggered  // user click-hold begins
  peak       // bloom fully expanded (~1.5s)
  fade       // graceful collapse (~2s)
}
```

Total duration: ~3.5 seconds (1.5 expand, 2 fade).

Bloom can trigger only once per session (guarded in context) to maintain mystique.

## Implementation Scaffold

### Proof.tsx

```tsx
// src/sections/Proof.tsx
import { useState, useEffect } from 'react';
import { useOrbitSystem } from '@/context/OrbitSystem';
import { motion } from 'framer-motion';
import { ThreeConstellation } from '@/components/ThreeConstellation';
import { useReducedMotion } from '@/hooks/useReducedMotion';

export function Proof() {
  const { animateTo, triggerBloom } = useOrbitSystem();
  const prefersReduced = useReducedMotion();
  const [blooming, setBlooming] = useState(false);

  const handlePointerDown = () => {
    if (!blooming) {
      setBlooming(true);
      triggerBloom(); // broadcast to constellation and emblem
      setTimeout(() => setBlooming(false), 4000); // reset after fade
    }
  };

  return (
    <section
      id="proof"
      onPointerDown={handlePointerDown}
      onPointerUp={() => setBlooming(false)}
      className="relative h-[160svh] select-none"
    >
      <motion.div
        className="sticky top-0 h-screen"
        animate={{ filter: blooming ? 'blur(2px) brightness(1.4)' : 'none' }}
        transition={{ duration: 1.2, ease: [0.33, 1, 0.68, 1] }}
      >
        {!prefersReduced && <ThreeConstellation blooming={blooming} />}
        {prefersReduced && <StaticProofBloom />}
      </motion.div>
      <OverlayText />
    </section>
  );
}
```

### OrbitSystem Context Extension

```tsx
// src/context/OrbitSystem.tsx
import { createContext, useContext, useRef } from 'react';
import { useMotionValue } from 'framer-motion';

const OrbitContext = createContext(null);

export function OrbitProvider({ children }) {
  const scrollProgress = useMotionValue(0);
  const scrollVelocity = useMotionValue(0);
  const bloomSignal = useMotionValue(0); // drives bloom intensity across system

  function triggerBloom() {
    bloomSignal.set(1);
    // fade back to 0 over 4s
    let t = 0;
    const fade = () => {
      t += 0.02;
      const next = Math.max(0, 1 - t / 4);
      bloomSignal.set(next);
      if (next > 0) requestAnimationFrame(fade);
    };
    fade();
  }

  function animateTo(mode, duration = 0.6) {
    // existing transition system logic
  }

  return (
    <OrbitContext.Provider value={{ scrollProgress, scrollVelocity, bloomSignal, triggerBloom, animateTo }}>
      {children}
    </OrbitContext.Provider>
  );
}

export const useOrbitSystem = () => useContext(OrbitContext);
```

### ThreeConstellation Bloom Logic

```tsx
// src/components/ThreeConstellation.tsx
import * as THREE from 'three';
import { useFrame } from '@react-three/fiber';
import { useRef } from 'react';
import { useConstellation } from '@/hooks/useConstellation';
import { useOrbitSystem } from '@/context/OrbitSystem';

export function ThreeConstellation({ blooming = false }) {
  const group = useRef<THREE.Group>(null);
  const { points, links, uniforms } = useConstellation();
  const { bloomSignal } = useOrbitSystem();

  useFrame((_, delta) => {
    uniforms.uTime.value += delta;
    // Smooth bloom pulse from motion value
    const b = bloomSignal.get();
    uniforms.uBloom.value = THREE.MathUtils.lerp(uniforms.uBloom.value, b, 0.08);
  });

  return (
    <group ref={group}>
      <points>
        <bufferGeometry>
          <bufferAttribute
            attach="attributes-position"
            args={[points.positions, 3]}
          />
        </bufferGeometry>
        <shaderMaterial
          uniforms={uniforms}
          vertexShader={VERT}
          fragmentShader={FRAG}
          transparent
          depthWrite={false}
          blending={THREE.AdditiveBlending}
        />
      </points>
      <lineSegments>
        <bufferGeometry>
          <bufferAttribute
            attach="attributes-position"
            args={[links.positions, 3]}
          />
        </bufferGeometry>
        <lineBasicMaterial
          color="#7df"
          transparent
          opacity={0.3}
        />
      </lineSegments>
    </group>
  );
}

const VERT = /* glsl */ `
  uniform float uTime;
  uniform float uBloom;
  varying float vIntensity;
  void main() {
    float pulse = sin(uTime * 2.0 + position.x * 0.1) * 0.1;
    vec3 pos = position;
    pos.xy *= 1.0 + uBloom * 0.6; // radial expansion
    vIntensity = 0.6 + (uBloom * 1.4) + pulse;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    gl_PointSize = 2.0 + uBloom * 8.0;
  }
`;

const FRAG = /* glsl */ `
  varying float vIntensity;
  void main() {
    float d = length(gl_PointCoord - 0.5);
    if (d > 0.5) discard;
    gl_FragColor = vec4(0.4 + 0.3*vIntensity, 0.8, 1.0, (1.0 - d) * vIntensity);
  }
`;
```

### Emblem Echo Pulse

// src/components/emblem/Emblem.tsx
import { motion, useTransform } from 'framer-motion';
import { useOrbitSystem } from '@/context/OrbitSystem';

export function Emblem() {
  const { bloomSignal } = useOrbitSystem();
  const scale = useTransform(bloomSignal, [0, 1], [1, 1.3]);
  const opacity = useTransform(bloomSignal, [0, 1], [1, 1.5]);

      className="pointer-events-none absolute inset-0 flex items-center justify-center"
      style={{ scale, opacity }}

        <circle cx="60" cy="60" r="40" fill="none" stroke="currentColor" strokeWidth="2" />
      </svg>
    </motion.div>
  );
}

## Interaction Flow

1. User reaches **Proof** section.
2. User **clicks and holds** anywhere on the constellation.
3. OrbitSystem broadcasts `bloomSignal → 1`.
4. * Constellation expands 60% outward.
   * Node size and brightness surge.
   * Emblem pulses outward in sync.
   * Background light subtly rises.
5. Over 4 seconds, everything **returns to stillness** — lines fade back, brightness normalizes.
6. The user continues scrolling; Bloom cannot re-trigger (once-per-session).

## Accessibility

* Bloom is *decorative* but should have `aria-live="polite"` message for screen readers:

  > “Constellation expanded — network aligned momentarily.”
* The `triggerBloom()` function can announce via a live region for ARIA compliance.
* Avoid sound or haptics unless explicitly enabled in settings.

---

## Performance Guidelines

* Single shader uniform update per frame (`uBloom`); negligible cost.
* Particle count capped at ≤ 100.
* Bloom expansion handled on GPU; no reallocation or React re-renders.
* Transition total ≤ 4s.

## Acceptance Criteria

1. **Trigger:** click-and-hold → bloom initiates, one-time per session.
2. **Animation:** constellation expands radially, emblem pulses, brightness rises.
3. **Duration:** total ~3.5–4s, smooth easing and return to stillness.
4. **A11y:** ARIA live announcement, reduced-motion fallback with static SVG.

6. **Continuity:** Bloom occurs only in Proof phase; gracefully transitions to Vortex act.
