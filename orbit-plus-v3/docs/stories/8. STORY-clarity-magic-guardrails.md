## Title

Clarity & Magic Guardrails — The Systemic Foundation

## Purpose

Establish global design, motion, and development standards ensuring every interaction balances **clarity (70%)** and **magic (30%)** across all acts of *Orbit-Plus V3*.
This story defines **cross-component motion constants**, **responsiveness principles**, **interaction physics**, and **semantic accessibility patterns** to preserve visual coherence and performance discipline throughout the experience.

---

## Philosophy

| Axis       | Clarity                                              | Magic                                                   |
| ---------- | ---------------------------------------------------- | ------------------------------------------------------- |
| Function   | Maintain legibility, pacing, and responsiveness.     | Introduce subtle transformation and organic reaction.   |
| Motion     | Communicate state change; align with user action.    | Express system personality through elasticity or light. |
| Emotion    | Predictable → trustworthy.                           | Surprise → memorable.                                   |
| Constraint | 60 FPS, ≤ 16 ms main-thread tasks, no layout thrash. | GPU-only transforms, opacity, filters ≤ 1.              |

## 2. Motion Physics Hook

Ensures consistent, composable springs for emblem, portal, and constellation.

```ts
// src/hooks/useMotionPhysics.ts
import { useSpring, MotionValue } from 'framer-motion';
import { MOTION } from '@/styles/motion';

export function useMotionPhysics(value: MotionValue<number>, type: 'spring'|'soft') {
  const cfg = type === 'soft' ? MOTION.ease.softSpring : MOTION.ease.spring;
  return useSpring(value, { stiffness: cfg.stiffness, damping: cfg.damping });
}
```

Example:

```ts
const rpm = useMotionPhysics(scrollVelocity, 'soft');
```

## 4. Responsive Motion Scaling

Clarity requires accessibility parity; scale motion by user/device capability.

```ts
// src/hooks/useMotionScale.ts
import { useReducedMotion } from '@/hooks/useReducedMotion';
export function useMotionScale(prefersReduced:boolean, base:number) {
  if (prefersReduced) return base * 0.5;
  const isMobile = window.matchMedia('(max-width: 768px)').matches;
  return base * (isMobile ? 0.8 : 1);
}
```

Usage:

```ts
const radius = useMotionScale(prefersReduced, 84);
```

## 7. Accessibility Guardrails

```ts
// src/utils/a11y.ts
export function announce(message: string) {
  const region = document.getElementById('live-region');
  if (region) {
    region.textContent = '';
    requestAnimationFrame(() => { region.textContent = message; });
  }
}

// global region in _app.tsx
<div id="live-region" role="status" aria-live="polite" className="sr-only" />
```

Use anywhere a non-visual state changes (e.g., Proof Bloom, form success):

```ts
announce('Constellation expanded — network aligned momentarily.');
```

## 8. Interaction Physics — Scroll & Velocity Mapping

### Principles

* All scroll-driven sections share normalized progress from `OrbitSystem`.
* `scrollVelocity` mapped to `[−4, 4]` range to prevent runaway rotations.
* Use smoothing spring to avoid stutter between acts.

```ts
// Typical usage inside a section
const vAbs = useTransform(scrollVelocity, (v) => Math.min(4, Math.abs(v)));
const rpmFactor = useSpring(vAbs, MOTION.ease.softSpring);
```
