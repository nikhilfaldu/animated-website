# docs/stories/STORY-emblem-dynamics.md

## Title

Emblem Dynamics — Breathing, Attention, and Idle Intelligence

## Goal

Make the emblem feel perceptive and alive by coupling scroll state, cursor proximity, and idle timing into a single, coherent behavior model that never compromises clarity or performance.

## Narrative Link

“The emblem isn’t just a logo — it’s a living orbital system”. Dynamics must reinforce Act 1–5 transformations without becoming UI noise. OrbitSystem is the source of truth for motion values and states.

---

## Behavior Model (authoritative)

**Inputs**

* Scroll progress and velocity from OrbitSystem
* Pointer position and velocity (desktop), coarse pointer sampling on touch
* Idle timers (short idle ≈ 3s, deep idle ≈ 8s)

**Outputs**

* Subtle positional drift toward pointer (attention)
* Centrifugal flare under fast scrolling (energy)
* Low amplitude “breath” in idle states (aliveness)

**States**

* `active` (scrolling)
* `attentive` (pointer present, low scroll)
* `resting` (short idle) → `deepRest` (long idle)

**Non-goals**

* No erratic wobble
* No nav hit-test interference
* No readability loss

## Data flow & motion values

**OrbitSystem extensions (non-breaking):**

* `scrollVelocity`: already part of the design; ensure it’s a Framer `MotionValue<number>`
* `activityState`: derived enum from velocity thresholds

```ts
// In OrbitSystem.tsx (shape; aligns with CLAUDE.md patterns):contentReference[oaicite:12]{index=12}
const scrollVelocity = useMotionValue(0) // updated by ScrollController
const activityState = useTransform(scrollVelocity, v => {
  if (Math.abs(v) > 2.0) return 'active'
  return 'attentive'
})
```

**Pointer capture in Emblem**
Prefer a single global pointer listener to avoid rebinds and to keep Emblem decoupled from DOM layout. Use motion values for x,y targets to avoid layout reads.

```ts
// Emblem.tsx (sketch)
const prefersReduced = useReducedMotion()
const pointerX = useMotionValue(0)
const pointerY = useMotionValue(0)
const hasPointer = useMotionValue(false)

// On mount: throttle mousemove
useEffect(() => {
  const onMove = (e: MouseEvent) => {
    hasPointer.set(true)
    pointerX.set(e.clientX)
    pointerY.set(e.clientY)
  }
  const onLeave = () => hasPointer.set(false)
  window.addEventListener('mousemove', onMove, { passive: true })
  window.addEventListener('mouseleave', onLeave, { passive: true })
  return () => {
    window.removeEventListener('mousemove', onMove)
    window.removeEventListener('mouseleave', onLeave)
  }
}, [])
```

**Center-relative vector**
Compute a small normalized vector from emblem center to pointer, then spring it to remove jitter. App currently fixes emblem at viewport center in `App.tsx` (`fixed top-1/2 left-1/2`).

```ts
// center in CSS pixels
const centerX = typeof window !== 'undefined' ? window.innerWidth / 2 : 0
const centerY = typeof window !== 'undefined' ? window.innerHeight / 2 : 0

const rawDx = useTransform(pointerX, x => x - centerX)
const rawDy = useTransform(pointerY, y => y - centerY)

// Normalize and clamp to max drift
const maxDriftPx = 12 // desktop; 6 on mobile
const normDx = useTransform(rawDx, dx => Math.max(-1, Math.min(1, dx / centerX)))
const normDy = useTransform(rawDy, dy => Math.max(-1, Math.min(1, dy / centerY)))

// Spring smoothing to avoid jitter; Motion best practice
const driftX = useSpring(normDx, { stiffness: 120, damping: 20, mass: 0.4 })
const driftY = useSpring(normDy, { stiffness: 120, damping: 20, mass: 0.4 })

// Final px offsets, gated by hasPointer and reduced motion
const proximityX = useTransform([driftX, hasPointer], ([dx, hp]) => (hp ? dx * maxDriftPx : 0))
const proximityY = useTransform([driftY, hasPointer], ([dy, hp]) => (hp ? dy * maxDriftPx : 0))
```

## Velocity flare (centrifugal energy)

Use OrbitSystem’s `scrollVelocity` to create slight radial spread and micro-rotation that decays when velocity drops. Keep amplitudes tight so type and nav are never destabilized.

```ts
// Access OrbitSystem motion values
const { scrollVelocity, scale, rotateZ } = useOrbitSystem() // shape per CLAUDE.md:contentReference[oaicite:14]{index=14}

// Map velocity to small effects
const vAbs = useTransform(scrollVelocity, v => Math.min(4, Math.abs(v)))

// 0 → 1 energy factor
const energy = useTransform(vAbs, [0, 1, 4], [0, 0.4, 1])

// Slight rotation flare
const flareRotate = useTransform(energy, e => e * 2.5) // degrees

// Slight scale flare (radials feel like they “push out” under speed)
const flareScale = useTransform(energy, e => 1 + e * 0.02) // up to +2%

// Smooth with springs
const sFlareRot = useSpring(flareRotate, { stiffness: 80, damping: 18 })
const sFlareScale = useSpring(flareScale, { stiffness: 80, damping: 18 })
```

Combine with proximity offsets when composing the emblem’s wrapper transform:

```tsx
<motion.div
  style={{
    // Base transforms are already driven by OrbitSystem state
    // Additive micro-dynamics here:
    x: prefersReduced ? 0 : proximityX,
    y: prefersReduced ? 0 : proximityY,
    rotateZ: prefersReduced ? 0 : sFlareRot,
    scale: prefersReduced ? 1 : sFlareScale,
  }}
  className={clsx("pointer-events-none", className)}
>
  {/* SVG emblem paths using EMBLEM_PATHS, etc. */}
</motion.div>
```

## Idle breath (aliveness)

Drive a low-frequency, low-amplitude oscillation that pauses under activity. Use a time accumulator tied to `requestAnimationFrame` to avoid setInterval drift. Gate with reduced motion.

```ts
const t = useMotionValue(0)
useEffect(() => {
  let raf = 0
  const loop = (now: number) => {
    t.set(now / 1000) // seconds
    raf = requestAnimationFrame(loop)
  }
  raf = requestAnimationFrame(loop)
  return () => cancelAnimationFrame(raf)
}, [])

// Breath amplitude and frequency
const breathAmp = 0.008 // 0.8% scale
const breathFreq = 0.25 // Hz

const breathScale = useTransform(t, time => 1 + breathAmp * Math.sin(2 * Math.PI * breathFreq * time))

// State gating: only when idle for >3s, and reduce amplitude after 8s
const { scrollVelocity: v } = useOrbitSystem()
const isIdleShort = useTransform(v, vel => Math.abs(vel) < 0.2)
const idleGate = useSpring(isIdleShort, { stiffness: 200, damping: 30 })

const finalBreathScale = useTransform([breathScale, idleGate], ([b, gate]) => (gate ? b : 1))
```

Fold `finalBreathScale` into the same wrapper `style.scale` by multiplying via `useTransform` composition, or apply to a child group so it composes cleanly with the flare scale. Keep breath disabled if `prefersReducedMotion` is true.

## Per-radial micro-response (optional Phase 2)

If the emblem renders 32 paths from `EMBLEM_PATHS`, you can bias minor transform per radial based on pointer angle to suggest “orientation toward attention” without visible distortion.

* Compute pointer angle relative to center: `atan2(dy, dx)`
* For each radial index `i`, compute angular offset and map to a ±0.5 degrees local rotate or ±0.5% local scale.
* Never shift paths’ absolute positions; only local transforms to avoid aliasing.

## Layering, hit testing, and nav safety

* Keep emblem container `pointer-events: none` so GlobalNav remains interactive, per V2 parity requirements.
* If a child layer must receive events later, confine events to that child and never on the root.
* Ensure `z-index` places nav above the emblem when revealed.

---

## Accessibility

* `prefers-reduced-motion`: disable proximity drift, flare, and breath; keep emblem deterministic and static.
* Keyboard users must not experience focus jumps caused by dynamic transforms. Keep nav focus rings stable.
* Do not encode critical meaning solely in motion.

---

## Performance & budgets

* GPU transforms only (`transform`, `opacity`).
* No layout reads in rAF loops.
* Batch any future per-radial transforms in a single component render pass.
* Target 60 FPS; tail off springs quickly to avoid long tails.
* Global particle cap remains 200 across site; emblem dynamics must not spawn new particles.

## Acceptance criteria

1. Proximity drift ≤ 12 px desktop, ≤ 6 px touch; no conflict with GlobalNav hit testing.
2. Velocity flare never exceeds +2.5 degrees rotation or +2% scale.
3. Idle breath amplitude ≤ 0.8% scale, frequency ≤ 0.25 Hz, gated by idle.
4. All dynamics disabled under `prefers-reduced-motion`.
5. No cumulative transform drift; emblem recenters within 100 ms after activity ends.
6. 60 FPS on modern laptops; no animation blocks main thread > 16 ms on average.

---

## Phased delivery

* **Phase 1:** Proximity drift + velocity flare + reduced motion gating.
* **Phase 2:** Idle breath + per-radial micro-responses.
* **Phase 3:** Fine-tune springs, thresholds, and compose with section state transitions.

## Notes on integration with section states

* Emblem dynamics are additive micro-behaviors layered over the primary states `assembly`, `orbit`, `data`, `vortex` controlled by `animateTo` and `setCustomTransform`.
* During Hero assembly, clamp or fully disable micro-behaviors until lock to avoid competing cues.
* Ensure theme flip and portal transitions remain deterministic and unaffected.
