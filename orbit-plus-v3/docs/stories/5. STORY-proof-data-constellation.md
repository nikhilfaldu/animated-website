## Title

Proof — The Data Constellation

## Goal

Transform the “proof” phase into a **data-driven constellation** where prior creative energy (from the Machine) stabilizes into a structured, glowing network. The user should feel the satisfaction of pattern recognition: the invisible architecture of ideas now made visible.

This section demonstrates the *clarity after creation*—order emerging from motion.
Technically, it merges the **scroll-anchored emblem system** with a lightweight **WebGL/Three.js particle layer** that forms the constellation grid.

## Narrative Link

Act 4: Proof. The emblem becomes an analytical field. Each output from the Process section is absorbed as a “node” in the constellation; nodes connect dynamically as the user scrolls deeper, revealing the hidden logic of creativity.

## Section Scaffold

```tsx
// src/sections/Proof.tsx
import { Canvas } from '@react-three/fiber';
import { useScroll, useSpring, useTransform } from 'framer-motion';
import { motion, useMotionValueEvent } from 'framer-motion';
import { useRef, useState } from 'react';
import { useOrbitSystem } from '@/context/OrbitSystem';
import { ThreeConstellation } from '@/components/ThreeConstellation';
import { useReducedMotion } from '@/hooks/useReducedMotion';

export function Proof() {
  const { animateTo, scrollProgress } = useOrbitSystem();
  const prefersReduced = useReducedMotion();
  const ref = useRef<HTMLDivElement>(null);

  const { scrollYProgress } = useScroll({
    target: ref,
    offset: ['start 80%', 'end 20%'],
  });

  const opacity = useSpring(useTransform(scrollYProgress, [0, 0.2, 0.8, 1], [0, 1, 1, 0]), {
    stiffness: 80,
    damping: 16,
  });

  useMotionValueEvent(scrollYProgress, 'change', (v) => {
    if (v < 0.05) animateTo('data');
    if (v > 0.95) animateTo('vortex');
  });

  return (
    <section id="proof" ref={ref} className="relative h-[160svh]">
      <motion.div className="sticky top-0 h-screen" style={{ opacity }}>
        {!prefersReduced && <ConstellationScene />}
        {prefersReduced && <StaticDiagram />}
        <OverlayText />
      </motion.div>
    </section>
  );
}

function OverlayText() {
  return (
    <div className="absolute inset-0 flex flex-col items-center justify-center text-center pointer-events-none">
      <h2 className="font-display text-5xl text-fg">Proof of Concept</h2>
      <p className="max-w-md mt-4 text-fg/70">
        Every idea leaves a trace. Zoom out, and they form a pattern.
      </p>
    </div>
  );
}
```

## 3D Constellation Layer

### R3F Component

```tsx
// src/components/ThreeConstellation.tsx
import * as THREE from 'three';
import { useFrame } from '@react-three/fiber';
import { useRef, useMemo } from 'react';
import { useConstellation } from '@/hooks/useConstellation';

export function ThreeConstellation() {
  const group = useRef<THREE.Group>(null);
  const { points, links, uniforms } = useConstellation();

  useFrame((_, delta) => {
    uniforms.uTime.value += delta;
  });

  return (
    <group ref={group}>
      {/* Points */}
      <points>
        <bufferGeometry attach="geometry">
          <bufferAttribute
            attach="attributes-position"
            args={[points.positions, 3]}
          />
        </bufferGeometry>
        <shaderMaterial
          attach="material"
          uniforms={uniforms}
          vertexShader={VERT}
          fragmentShader={FRAG}
          transparent
          depthWrite={false}
          blending={THREE.AdditiveBlending}
        />
      </points>

      {/* Lines (edges) */}
      <lineSegments>
        <bufferGeometry attach="geometry">
          <bufferAttribute
            attach="attributes-position"
            args={[links.positions, 3]}
          />
        </bufferGeometry>
        <lineBasicMaterial
          attach="material"
          color="#7df"
          transparent
          opacity={0.3}
        />
      </lineSegments>
    </group>
  );
}

const VERT = /* glsl */ `
  uniform float uTime;
  varying float vAlpha;
  void main() {
    vec3 pos = position;
    float flicker = sin(uTime * 2.0 + pos.x * 0.1) * 0.1;
    vAlpha = 0.8 + flicker;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    gl_PointSize = 2.0;
  }
`;

const FRAG = /* glsl */ `
  varying float vAlpha;
  void main() {
    float d = length(gl_PointCoord - 0.5);
    if (d > 0.5) discard;
    gl_FragColor = vec4(0.5, 0.8, 1.0, vAlpha * (1.0 - d));
  }
`;
```

## Data Hook

```tsx
// src/hooks/useConstellation.ts
import * as THREE from 'three';
import { useMemo } from 'react';

export function useConstellation() {
  const count = 80;
  const points = useMemo(() => {
    const positions = new Float32Array(count * 3);
    for (let i = 0; i < count; i++) {
      positions[i * 3 + 0] = (Math.random() - 0.5) * 8;
      positions[i * 3 + 1] = (Math.random() - 0.5) * 6;
      positions[i * 3 + 2] = (Math.random() - 0.5) * 4;
    }
    return { positions };
  }, []);

  const links = useMemo(() => {
    const positions = new Float32Array(count * 6);
    for (let i = 0; i < count; i++) {
      const a = i;
      const b = (i + Math.floor(Math.random() * 10) + 1) % count;
      positions.set(
        [
          points.positions[a * 3],
          points.positions[a * 3 + 1],
          points.positions[a * 3 + 2],
          points.positions[b * 3],
          points.positions[b * 3 + 1],
          points.positions[b * 3 + 2],
        ],
        i * 6
      );
    }
    return { positions };
  }, [points]);

  const uniforms = useMemo(
    () => ({
      uTime: { value: 0 },
    }),
    []
  );

  return { points, links, uniforms };
}
```

## Interaction Model

* **Hover:** nearest node brightens; nearby edges pulse outward using additive blending.
* **Scroll Velocity:** feeds into `uniforms.uTime` multiplier → faster flicker.
* **Click-Hold:** temporarily locks current constellation, increases bloom intensity, symbolizing insight crystallization.

```tsx
// Example: capturing hover / click state inside ThreeConstellation
useFrame(({ mouse, camera }) => {
  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObject(pointsRef.current!);
  uniforms.uHover.value = intersects.length > 0 ? 1.0 : 0.0;
});
```

## Accessibility

* Provide static SVG fallback (`StaticDiagram`) for users with motion reduction or GPU limits.
* `<Canvas>` uses `role="img"` + `aria-label="Constellation visualization of data connections"`.
* Overlay text conveys meaning; no critical info encoded in motion only.

---

## Performance

* Particle count ≤ 100 for baseline devices.
* Use **instanced geometry** and single shader material (done).
* No dynamic re-allocation in render loop.
* Limit uniform updates to minimal set (`uTime`, optional `uHover`).
* Avoid heavy post-processing; use additive blending instead of bloom for performance.

---

## Transition Logic

**From Process → Proof:**

* Emblem fades into flattened data mode (using `animateTo('data')`).
* Machine output chips fade into constellation nodes (conceptual continuity).

**From Proof → Contact (Vortex):**

* Node connectivity gradually loosens; constellation drifts apart (opacity decays to 0).
* Trigger `animateTo('vortex')` when `scrollYProgress > 0.95`.

---

## Acceptance Criteria

1. Constellation forms smoothly as user enters section; 60 FPS target.
2. Scroll velocity influences flicker rate and node activity.
3. Hover produces localized brightening without frame-drop.
4. Emblem transition in/out synchronized with section entry/exit via `animateTo`.
5. Reduced-motion variant renders static SVG diagram with equal semantic clarity.
6. Performance budget: ≤ 2 ms GPU frame cost on M2 Air baseline.
