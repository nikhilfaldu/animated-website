  • 03

    MERIDIAN

     LIVE GITHUB

    The Earth as it is at this moment, in the browser. Sunlight falls where it really falls, the terminator sits where it really is, and city lights come on down the night side as the planet turns. Everything on screen is a real position: 16,003 tracked objects in orbit from published orbital elements, 41,411 catalogued stars behind them, every earthquake the USGS has reported in the past day, and the auroral ovals sized by the current geomagnetic activity. The clock runs live, or you can scrub a day either side of now and watch the whole thing follow.

    • three.js
    • TypeScript
    • GLSL
    • SGP4
  • 04

    BLUEBOOK

     CHART DOWNLOAD GITHUB

    A full three-statement operating model and DCF valuation of Greggs plc, generated from Python and delivered as a live Excel workbook — every forecast cell a real formula, driven off one scenario switch. The point is that it is machine-verified rather than asserted: the generated file is recalculated through headless LibreOffice and compared cell by cell against the Python model behind it, 730 cells per scenario across three scenarios, and every formula is parsed into a reference graph and proved acyclic. Historical figures carry a page citation to the filing they came from.

    • Python
    • openpyxl
    • Financial modelling
    • DCF / LBO / Comps
