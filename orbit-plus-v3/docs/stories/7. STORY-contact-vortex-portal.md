# docs/stories/STORY-contact-vortex-portal.md

## Title

Contact — Vortex Portal (Emblem → Portal → Form)

## Goal

Transform the emblem into a stable **portal** that focuses attention on a frictionless contact form. Motion communicates commitment; clarity governs the form. 60 FPS, GPU-only transforms, reduced-motion parity.

## Narrative Link

Act 5 (Connection): After Proof, the system releases into a calm vortex that **opens a channel**. The emblem dissolves into a circular portal; the form appears inside the aperture. Subtle centrifuge on focus narrows distractions; on submit, a brief supernova settles into confirmation.

## Files to Touch

* `src/sections/Contact.tsx` — section shell, sticky viewport, form, submission states.
* `src/components/PortalVortex.tsx` — the animated portal (clip-path/sdf), emblem handoff.
* `src/context/OrbitSystem.tsx` — expose `animateTo('vortex')` on entry; `animateTo('orbit')` on exit.
* `src/hooks/useReducedMotion.ts` — gate animations.
* `src/components/forms/Input.tsx`, `Textarea.tsx`, `Submit.tsx` — accessible inputs with error helpers.

## Section Scaffold

```tsx
// src/sections/Contact.tsx
import { motion, useSpring, useTransform } from 'framer-motion';
import { useEffect, useRef, useState } from 'react';
import { useOrbitSystem } from '@/context/OrbitSystem';
import { useReducedMotion } from '@/hooks/useReducedMotion';
import { PortalVortex } from '@/components/PortalVortex';
import { Input, Textarea, Submit } from '@/components/forms';

export function Contact() {
  const { animateTo } = useOrbitSystem();
  const prefersReduced = useReducedMotion();
  const [phase, setPhase] = useState<'ingress'|'ready'|'submitting'|'success'|'error'>('ingress');

  useEffect(() => {
    animateTo('vortex', 0.8);               // emblem → vortex pose
    const t = setTimeout(() => setPhase('ready'), prefersReduced ? 50 : 700);
    return () => clearTimeout(t);
  }, [animateTo, prefersReduced]);

  return (
    <section id="contact" className="relative h-[140svh]">
      <div className="sticky top-0 h-screen grid place-items-center">
        <motion.div
          initial={false}
          animate={{ background: phase === 'ready' || phase === 'success' ? 'radial-gradient(1200px circle at 50% 50%, var(--bg-strong), var(--bg))' : 'var(--bg)'}}
          className="absolute inset-0 -z-10"
          aria-hidden
        />
        <PortalVortex phase={phase} />

        <ContactCard
          phase={phase}
          onSubmitStart={() => setPhase('submitting')}
          onSubmitSuccess={() => setPhase('success')}
          onSubmitError={() => setPhase('error')}
        />
      </div>
    </section>
  );
}
```

## Portal (clip-path + field-focus narrowing)

**Why clip-path?** Cheap, GPU-friendly, easy to sync with emblem origin. We keep the emblem layer `pointer-events:none`; the button/inputs sit above.

```tsx
// src/components/PortalVortex.tsx
import { motion, useSpring, useTransform } from 'framer-motion';
import { useEffect } from 'react';
import { useOrbitSystem } from '@/context/OrbitSystem';
import { useReducedMotion } from '@/hooks/useReducedMotion';

type Props = { phase: 'ingress'|'ready'|'submitting'|'success'|'error' };

export function PortalVortex({ phase }: Props) {
  const { originX, originY, bloomSignal } = useOrbitSystem(); // origin shares emblem center; bloom used as subtle brightness echo
  const prefersReduced = useReducedMotion();

  // Portal radius (0→1 viewport unit scaled)
  const r = useSpring(0, { stiffness: 140, damping: 18 });
  const swirl = useSpring(0, { stiffness: 120, damping: 20 }); // degrees

  useEffect(() => {
    if (prefersReduced) { r.set(1); return; }
    if (phase === 'ingress') { r.set(0.95); swirl.set(220); }      // open
    if (phase === 'ready')   { r.set(1.0);  swirl.set(260); }      // settle
    if (phase === 'submitting') { r.set(1.1); swirl.set(360); }    // brief expansion
    if (phase === 'success') { r.set(0.8);  swirl.set(420); }      // calm close-in
    if (phase === 'error')   { r.set(0.95); swirl.set(260); }      // recover
  }, [phase, prefersReduced, r, swirl]);

  const clip = useTransform(r, v => `circle(${(v * 42).toFixed(2)}vmin at 50% 50%)`);
  const rotate = useTransform(swirl, s => `rotate(${s}deg)`);

  // Subtle bloom brightening
  const brightness = useTransform(bloomSignal, [0, 1], [1, 1.2]);

  return (
    <motion.div
      className="absolute inset-0 grid place-items-center pointer-events-none"
      style={{ filter: brightness.to(b => `brightness(${b})`) }}
      aria-hidden
    >
      {/* Swirling ring */}
      <motion.div
        className="h-[70vmin] w-[70vmin] rounded-full"
        style={{
          clipPath: clip,
          background: 'conic-gradient(from 0deg, rgba(125,223,255,.25), rgba(0,0,0,0) 20%, rgba(125,223,255,.2) 60%, rgba(0,0,0,0) 100%)',
          transform: rotate,
        }}
      />
      {/* Portal edge (clean outline for clarity) */}
      <motion.div
        className="absolute h-[62vmin] w-[62vmin] rounded-full border"
        style={{ borderColor: 'rgba(125,223,255,0.6)' }}
      />
    </motion.div>
  );
}
```

**Reduced-motion:** we snap the portal open without swirl.

## Contact Card (form + focus narrowing)

* **Focus narrowing**: when an input is focused, vignette gently deepens and portal rotates a few degrees to suggest attention.
* **Semantics**: standard `<form>` with labels, descriptions, and error text bound via `aria-describedby`.
* **No scroll trap**: page scroll still works; form occupies logical end of journey.

```tsx
// src/sections/Contact.tsx (continued)
function ContactCard({
  phase, onSubmitStart, onSubmitSuccess, onSubmitError
}: {
  phase: 'ingress'|'ready'|'submitting'|'success'|'error';
  onSubmitStart: () => void; onSubmitSuccess: () => void; onSubmitError: () => void;
}) {
  const disabled = phase === 'submitting' || phase === 'success';

  return (
    <div className="relative z-10 w-full max-w-[560px] px-6">
      <motion.form
        onSubmit={async (e) => {
          e.preventDefault();
          onSubmitStart();
          try {
            // Replace with real endpoint; keep timeboxed await to show animation
            await new Promise(res => setTimeout(res, 950));
            onSubmitSuccess();
          } catch {
            onSubmitError();
          }
        }}
        initial={false}
        animate={{
          filter: phase === 'ready' ? 'drop-shadow(0 8px 24px rgba(0,0,0,0.25))' :
                  phase === 'submitting' ? 'drop-shadow(0 10px 30px rgba(125,223,255,0.2))' :
                  phase === 'success' ? 'drop-shadow(0 6px 18px rgba(0,0,0,0.2))' : 'none',
          scale: phase === 'submitting' ? 1.02 : 1,
        }}
        transition={{ duration: 0.24 }}
        className="rounded-2xl bg-[color:var(--card)]/75 backdrop-blur-md p-6 ring-1 ring-white/10"
        aria-describedby="contact-desc"
      >
        <h2 className="font-display text-3xl text-fg text-center">Open the Channel</h2>
        <p id="contact-desc" className="mt-2 text-center text-fg/70">
          Tell me what you’re building. I’ll reply with clarity and options.
        </p>

        <div className="mt-6 grid gap-4">
          <Input id="name" label="Your name" required disabled={disabled} />
          <Input id="email" label="Email" type="email" required disabled={disabled} />
          <Input id="company" label="Company (optional)" disabled={disabled} />
          <Textarea id="message" label="What do you need?" rows={5} required disabled={disabled} />
        </div>

        <div className="mt-6 flex items-center justify-center gap-3">
          <Submit disabled={disabled} label={phase === 'submitting' ? 'Sending…' : (phase === 'success' ? 'Sent' : 'Send')} />
        </div>

        {phase === 'success' && (
          <motion.div
            initial={{ opacity: 0, y: 8 }}
            animate={{ opacity: 1, y: 0 }}
            className="mt-4 text-center text-emerald-400"
            role="status" aria-live="polite"
          >
            Message received. I’ll respond shortly.
          </motion.div>
        )}

        {phase === 'error' && (
          <motion.div
            initial={{ opacity: 0, y: 8 }}
            animate={{ opacity: 1, y: 0 }}
            className="mt-4 text-center text-red-400"
            role="alert"
          >
            Something went wrong. Please try again.
          </motion.div>
        )}
      </motion.form>
    </div>
  );
}
```

export const Input = forwardRef<HTMLInputElement, {

## Reduced-Motion Parity

* Form animates only via opacity/scale ≤ 1.02.
* Success/error messages fade without motion transforms.

## Performance Guardrails

* **GPU-only**: transform/opacity/clip-path; avoid layout in loops.
* No global shadow-DOM filters; use lightweight blur in short bursts only.
* Single spring per portal scalar + rotation; no timers other than submit handshake.
* Form logic async/await with timeouts for UX only; replace with real API later.

---

## Integration & Handoff

* **Enter Contact**: `animateTo('vortex')` aligns emblem to portal origin.
* **On success**: keep user on page; show CTA (“Send another” or “Return to Orbit”). `animateTo('orbit')` on exit if user navigates away.
* **From Proof**: opacity cross-fade on Proof constellation while portal opens (ensure z-index: portal above but non-interactive).

---

## Acceptance Criteria

1. **Portal Morph**: emblem handoff feels continuous; portal stabilizes within ~700 ms (or 50 ms with reduced motion).
2. **Focus Narrowing**: focusing a field subtly deepens vignette; no legibility loss.
3. **Form A11y**: labels, required markers, error text with `role="alert"`; keyboard order natural; focus rings visible.
4. **Submit Feedback**: “submitting” visual ≤ 1 s; success confirmation with live region; failure recovers without jank.
5. **Performance**: 60 FPS during ingress/submit burst on modern laptops; no long-running JS on main thread.
6. **Parity**: reduced-motion delivers equivalent meaning without swirl/expansion travel.

## Phase Plan

* **Phase 1**: Portal open/settle; accessible form; submit success/error; reduced-motion parity.
* **Phase 2**: Focus-linked vignette + slight portal precession; compact supernova burst.
* **Phase 3**: Add optional “send another / return to orbit” micro-journey with emblem echo pulse.

This keeps **70% clarity** (a calm, legible form in a focused portal) and **30% magic** (emblem-to-portal morph, light supernova on send), fully consistent with the current architecture.
