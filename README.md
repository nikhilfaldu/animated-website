# Projects

One folder per project. To run one:

```bash
cd <project-folder>
npm install
npm run dev
```

| Folder | Project |
|---|---|
| `award-winning-website/` | Zentry-style animated landing page (React, Vite, Tailwind, GSAP) |
| `portfolio-ver-2/` | Jonathan Jesni's 3D developer portfolio (Next.js, React Three Fiber, GSAP, Lenis, Matter.js) |
| `liquid-glass-carousel/` | Infinite WebGL image carousel with a liquid-glass lens shader (Next.js, three.js, GSAP) |
| `kage/` | Scroll-driven Three.js night walk through a Kyoto temple (static HTML — run `npx serve .` inside the folder) |
| `oberlab-turbofan-scroll/` | Scroll-driven procedural jet engine that assembles and spools up, with synthesized sound (static HTML — run `npx serve .` inside the folder) |
| `iron-man/` | Scroll-driven image-sequence hero with cinematic sections (Next.js, Framer Motion, Lenis) |
| `frontenddesignbasics/` | Frontend design guide site — tools, principles and live demos (Next.js; uses pnpm: `pnpm install` then `pnpm dev`) |
| `orbit-plus-v3/` | Orbit+ creative agency site with a scroll-driven 3D aperture emblem (React, Vite, React Three Fiber, Framer Motion, Lenis) |
| `the-architect-of-worlds/` | Cinematic 3D universe of explorable planets with an AI chat feature (Next.js, React Three Fiber, GSAP; AI needs `OPENAI_API_KEY` in `.env.local`) |
| `oriel/` | ORIEL concept watch story — Three.js watch that comes apart on scroll, with a configurator and product page (Vite, GSAP, Lenis) |
| `scroll-cinema/` | Scroll-Cinema template — scroll-scrubbed video + 3D hero landing page, with an AI-agent skill (static HTML — run `npx serve .` inside the folder) |
